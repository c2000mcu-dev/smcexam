# SMC300 개발보드 예제 자료 이전 결과

작업일: 2026-11-03

- 게시물 25개를 확인했습니다. 자료가 있는 예제 24개에서 파일 74개를 이전했고, 자료 없는 공지 1개는 수정하지 않았습니다.
- 공개 다운로드를 원본 SHA-256과 대조하고 게시물의 자료 링크 및 첨부 등록을 정리했습니다. 본문 텍스트와 다른 링크를 보존했습니다.
- SFTP 파일 59개를 삭제하고, 다른 게시물에서 사용하는 파일 0개는 보존했습니다.
- 배선도와 작업 경로 안내 등 자료 이미지 42개의 본문 표시 주소도 GitHub로 함께 교체했습니다.
- 다른 게시판 77개에서 자료 링크를 검색하고 게시물 2개를 읽어 참조 관계를 확인했습니다.
- 저장 과정에서 CDN 주소로 변경된 본문 이미지 0개도 변경 전후 SHA-256이 일치했습니다.
- 원본 파일과 수정 전 본문은 작업자의 로컬에 별도로 백업했습니다. 인증 정보와 관리자 HTML은 이 저장소에 포함하지 않았습니다.
